# What next?

You've read through the getting-started guides, the core concepts, the module
chapters, and the ecosystem integrations.  Here's where to go from here.

## Pointers

- **[docs.rs API reference](https://docs.rs/raylib)** — the full rustdoc for
  every public type, function, and trait in `raylib`.  Use the search bar and
  the **Feature flags** panel to browse feature-gated items (`glam`, `mint`,
  `serde`, `raygui`, …).

- **[Upstream raylib](https://www.raylib.com/)** — the C library reference,
  the official cheatsheet, examples, and a community forum.  When a function
  isn't documented in the Rust side, the C docs are the authoritative source.

- **[The showcase](https://github.com/raylib-rs/raylib-rs/tree/unstable/showcase)**
  — WS9 (the 6.0 finale) will port the full set of official raylib examples to
  Rust and deploy them as a GitHub Pages gallery.  The portfolio lives under
  `showcase/` in the repository today; the hosted gallery will appear when WS9
  ships.

- **[The repository](https://github.com/raylib-rs/raylib-rs)** — source code,
  issue tracker, and the `docs/superpowers/` directory which holds the spec and
  plan archive for the entire 6.0 upgrade effort.

- **[CONTRIBUTE.md](https://github.com/raylib-rs/raylib-rs/blob/unstable/CONTRIBUTE.md)**
  — contribution guide covering `unsafe` conventions, RAII expectations, the
  `# Safety` / `// SAFETY:` comment discipline, and the PR process.
